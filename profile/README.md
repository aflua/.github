# Aflua

**Desenvolvedora independente de software. Criamos e mantemos produtos digitais próprios.**

## Sobre

A Aflua desenvolve, opera e mantém seus próprios produtos de software. Não prestamos serviços sob encomenda: cada projeto aqui nasce para resolver um problema real, ser usado por pessoas de verdade e se sustentar no longo prazo.

O nome vem de *afluente*, o rio menor que deságua em outro e o torna maior. Cada produto da Aflua funciona da mesma forma: independente, com propósito próprio e contribuindo para algo maior.

## Princípios

- **Simplicidade.** Software que qualquer pessoa entende e usa sem precisar de treinamento.
- **Preço justo e transparente.** Planos claros, sem taxas escondidas e sem surpresas na cobrança.
- **Privacidade por padrão.** Coletamos apenas os dados necessários para o produto funcionar.
- **Melhoria contínua.** Nossos produtos evoluem a partir do uso real de quem confia neles.
